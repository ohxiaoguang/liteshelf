# Changelog

## 1.0.1

- Explicitly use HFS+ for distribution DMGs to avoid the hosted macOS 27 runner’s default folder-image creation failure.

## 1.0.0

- Native SwiftUI icon grid, search, keyboard launch and Finder integration.
- Recursive discovery restricted to user-selected game folders.
- JSON library, persistent native icons and security-scoped folder bookmarks.
- External-volume notifications, offline records and permission recovery.
- English and Simplified Chinese localization following macOS preferences.
- ARM64 Xcode build, unit tests, automatic DMG packaging and tag-based releases.
- Optional Developer ID signing, Apple notarization and stapling.
